# 8월 22일 의사 결정 목록

---

1. 월별 택시 운행 데이터 이름과 저장 경로
   - 결정: DAG·작업·데이터셋 이름은 `monthly_taxi_trip`으로 통일한다.
   - Bronze는 `bronze/monthly_taxi_trip`, Silver는 `silver/monthly_taxi_trip`을 사용한다.
   - `hvfhv`는 TLC 원천의 차량 유형·컬럼명처럼 외부 계약을 설명할 때만 남긴다.

2. 기존 S3 객체 이관
   - S3 이관은 별도 승인된 운영 작업에서 수행한다.
   - 원본과 대상의 객체 수·총 크기를 비교한 뒤 DAG를 전환한다.
   - 기존 prefix 삭제는 이 작업에 포함하지 않는다. 검증과 롤백 기간이 끝난 뒤 별도 승인한다.

```bash
aws s3 ls s3://de-theone/bronze/hvfhv/ --recursive --summarize
aws s3 ls s3://de-theone/bronze/monthly_taxi_trip/ --recursive --summarize
aws s3 ls s3://de-theone/silver/hvfhv/ --recursive --summarize
aws s3 ls s3://de-theone/silver/monthly_taxi_trip/ --recursive --summarize
```

3. Bronze → Silver 실행 환경
   - 로컬은 기존 `BashOperator`로 Spark를 실행한다.
   - 운영(`SPARK_JOB_ENV=prod`)은 공용 EMR Serverless Application과 실행 역할에 Job Run을 제출하고 완료까지 기다린다.
   - Application ID·실행 역할 ARN·버킷은 배포 시 주입된 환경변수를 사용한다.

4. 가짜 원천 생성(`synthetic_driver_trip_source`) 실행 환경
   - 로컬은 기존 `BashOperator`, 운영(`SPARK_JOB_ENV=prod`)은 EMR Serverless에 제출한다.
   - EMR 워커는 Airflow 컨테이너 로컬 디스크를 볼 수 없어 입출력을 모두 S3로 옮긴다.
     - TLC 원본·zone lookup: `s3://de-theone/source/raw/`
     - 월별 기사·차량 스냅샷: `s3://de-theone/source/synthetic_driver_trip_state/`
     - Attribution·Published: 기존 `source/attribution/`·`source/published/` 유지
   - `--env prod`와 `--storage local` 조합은 job 시작 전에 거부한다.
   - `storage` 파라미터 기본값은 `SPARK_JOB_ENV`를 따라간다(`prod`면 `s3`).
