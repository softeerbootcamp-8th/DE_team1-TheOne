1. 가짜 데이터 합성 데이터 파이프라인 포함 여부
    > 가짜 데이터 합성하는 과정을 파이프라인에 포함해도 되나?
    - 결론 : 파이프라인에서 분리하기
    - 사유  
        1. 실제로는 저 데이터가 제공될 것이기 때문에 분리하는 것이 맞다.
        2. 우리가 만드는 것 전부를 파이프라인에 넣는 것이 아니다. 가상 환경을 만들기 위해서 하는 작업과 실제 데이터가 존재할 때 해야 하는 작업을 분리하자.
        3. 메인 프로덕트에는 실제 구성된 가상 환경에서 운영될 비즈니스 로직만 있어야 한다.
