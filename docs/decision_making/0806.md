# 8월 6일 의사 결정 목록


1. 차량 추천 개수
    > 차량 추천을 1대만 하면 되지 않을까?
    - 결론 : 차량 타입(X,Comport,XL)별 2개씩
    - 사유 : 같은 타입이어도 차량 별 특징이 다르기 떄문에, 고객에게 더 다양하게 제안해주기 위함

2. 예상 수입 값 추가 여부
    > 대시보드에 예상 수입을 넣을까?
    - 결론 : 예상 수입을 넣자.
    - 사유 : 차량 업그레이드를 통해 프리미엄 배차(Comport)를 받을 수 있는 경우를 고려할 것이기 떄문에 예상 수입을 넣자
        - 단순 절감 뿐만 아니라 추가 수익까지 고려한 차량 추천

3. 기사 집계 기간 
    > 기사 집계를 월/주 단위 중 어떤 것으로 해야할까?
    - 결론 : 주단위 집계/ 데이터 보여줄 때 집계 기간 명시
    - 사유 : 렌트료가 주 단위로 발생하므로, 주 단위 비교가 좋을 것 같다. 주 단위 순수익 추이를 보여줄 수 있도록 하면 좋을 것 같다. 
        - 1~7 / 8~14 / .../22~28/29-/ 이렇게 잘라서 보여주면, 마지막 기간(1~3일)에 계산된 순수익이 작아도 이해할 수 있을 것.

4. 휘발유/전기 수집
    > 휘발유와 전기 가격을 월/주/일 중 어떻게 수집할까?
    - 결론: 각각 개별 API를 이용하여 일 단위 평균으로 집계
        - 휘발유는 매일 가격이 달라지는 특징이 존재하기 때문, 전기 또한 자주 변할 수 있으므로 충전소 평균을 일별로 집계
    - 추후 : 전기값이 시간대 별로 다르다는 것을 고려할 수 있으면 고려하도록 수정
