# 두 결과를 하나의 스냅샷으로 원자적으로 적재
- 요약
  - 문제 : 한 달 운행 실적/추천 차량 결과 개별 저장 시 서로 다른 실행 결과가 함께 조회
  - 접근 : 두 테이블을 한 트랜잭션으로 적재
  - 검증 : 시나리오 기반 테스트 구성 후, 확인

## 문제
- 배경
  - Gold에서 생성하는 아래 두 데이터는 같은 계산/같은 기사 집합으로 만들어짐
    - 한 달 운행 실적
    - 기사별 추천 차량 결과
- 문제 : RDS에 따로 커밋하면 아래 문제가 생김
  1. 대시보드에서 서로 다른 결과를 함께 보여줄 수 있음
    - 문제 상황 : 운행 실적은 교체 성공(v2) / 추천 차량은 교체하다 실패(v1)
  2. 각 파일은 정상이라 파일 존재 여부로 검사 불가

## 접근
> 대시보드 공개 단위를 스냅샷 하나로 묶기 
- 월별 추천 스냅샷 : 기사별 한 달 운행 실적 & 기사별 추천 차량 결과
  - 공개 전 두 결과가 같은 기사 집합을 가지는지 확인

## 해결
> 트랜잭션 이용
- 각 결과에 버전을 붙이고, `하나의 트랜잭션으로 적재`
  - 두 테이블 행 수를 다시 조회해 아래 사항 검사 후, 커밋
    1. 예상 값과 같은지
    2. 0보다 큰지 (0으로 같으면 안 됨)
- 대시보드 : 지역/월 필터링 기준 `최신 완료 버전 조회`
## 검증
> 같은 실행에서 만들어진 두 결과만 읽는지 테스트 구성 후 검증
- 아래 시나리오별 테스트를 만들어 확인
  - **데이터 내용 검사** : `실제 행 수`가 `예상과 다르거나 0`이면 커밋 전 실패
  - **실패 롤백** : 트랜잭션 실패 시 `원자성에 따라 롤백 되는지` 확인
  - **DB 연결 전 실패** : `기사 누락시 DB 연결 전 실패` 확인
  - **대시보드 읽기 검증** : `최신 버전의 여러 기사 행을 모두 읽는지` 확인
